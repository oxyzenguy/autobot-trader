# ⚡ AutoBot Trader (업비트 하이브리드 멀티에셋 퀀트 자동매매 시스템)

> **업비트(Upbit) 실전 원화(KRW) 마켓 기반 3대 자산 맞춤형 하이브리드 자동매매 & 무손절 적립 퀀트 시스템**  
> 기축 자산(BTC)의 무손절 스마트 적립과 메이저 알트(ETH, SOL)의 국면전환 추세추종/마틴게일 이중 방어를 유기적으로 결합한 3중 포트폴리오 엔진입니다.

---

## 📊 1. 포트폴리오 구성 및 전략 개요

전체 자산은 **`1. 비트코인(BTC) ➔ 2. 이더리움(ETH) ➔ 3. 솔라나(SOL)`**의 엄격한 우선순위로 관리되며, 종목별 고유 특성에 맞춘 차별화된 퀀트 알고리즘이 적용됩니다.

```
[총 1,000만 원 자산 배분 구조]

 1. 비트코인 (KRW-BTC) ➔ 비중 ~55% (기존 잔고 포함 + 매일 1~3만 원 적립)
    └── 든든한 '베이스 캠프'이자 장기 자산 증식 엔진 (무손절 영구 수량 축적 Buy-Only)

 2. 이더리움 & 솔라나 (KRW-ETH, KRW-SOL) ➔ 비중 ~30% (각 100만 원 한도 배정)
    └── 현금을 벌어오는 '사냥꾼' (상승장 추세추종 익절 + 하락장 마틴-매직스플릿 방어)

 3. 원화 예수금 버퍼 (KRW) ➔ 비중 ~15% (130~260만 원 실탄)
    └── 비트코인 6개월 무중단 적립 보장 + 알트코인 급락 방어 유동성
```

## 🎯 2. 종목별 세부 매매 전략

### 🥇 1. 비트코인 (KRW-BTC) : 라오어식 무손절 계층형 가중 적립 (Tiered Smart DCA)
* **목표**: 비트코인은 절대 팔지 않고(No Stop-Loss, No Sell), 하락할 때 평단가를 파괴적으로 깎아내려 수량을 극대화.
* **기존 잔고 포함**: 기존 계좌 잔고를 모두 합산한 실제 계좌 평단가를 기준으로 세일 여부 실시간 판정.
* **시분할(Time Diversification) 2중 아키텍처**:
  1. **📱 업비트 자체 서버 예약 (매일 15:05 KST)**:
     * 통계적으로 하루 중 가장 가격이 저렴한 '골든 아워(15시)'에 **10,000원 무조건 자동 매수** (PC가 꺼져도 365일 무중단 기본 베이스).
  2. **🤖 로컬 봇 스마트 종가 판정 (매일 08:55 KST)**:
     * 일봉 캔들 마감 직전(08:55) 시장 200일선과 내 계좌 평단가를 비교하여 스마트 가중 매수 집행:
       * **☀️ 0단계 (상승 & 수익 중)**: `종가 >= 평단가` AND `종가 >= 200일선` ➔ **0원 추가** (무리한 추격매수 금지)
       * **⛅ 1단계 (일반 세일 구간)**: `종가 < 평단가` XOR `종가 < 200일선` ➔ **10,000원 추가 매수**
       * **⛈️ 2단계 (역대급 바겐세일)**: `종가 < 평단가` AND `종가 < 200일선` ➔ **20,000원 추가 매수!** (하루 총 3만 원 투입)
* **5년 풀사이클 백테스트 성과 (2021.10 ~ 2026.09, 1,791일)**:
  * 총 모은 비트코인: **0.627084 BTC** (단순 적립 대비 2배 이상 확보)
  * 평균 매수단가: **4,948만 원** (단순 적립 5,746만 원 대비 -800만 원 인하, 역대 최저 평단가)
  * 최종 수익률: **+134.85%** (전체 백테스트 전략 중 압도적 1위)

### 🥈 2. 이더리움 (KRW-ETH) & 🥉 3. 솔라나 (KRW-SOL) : 200 MA 하이브리드 국면전환 전략
200시간 이동평균선(200 MA)을 기준으로 시장을 **상승 국면(BULL)**과 **하락 국면(BEAR)**으로 완전 분리하여 대응합니다.

#### 🟢 상승 국면 (BULL: 현재가 > 200 MA)
* **진입**: 5/20 MA 골든크로스 발생 시 1 Unit(10,000원) 최초 진입.
* **포지션 빌드업 (2중 가산)**:
  1. **12시간 정기 분할적립 (Time-DCA)**: 12시간마다 1 Unit씩 추가 매수 (최대 20회차 = 20만 원 캡).
  2. **일봉 양봉 종가매매**: 08:50 KST 일봉이 전일 대비 양봉 마감 & 5일선 지지 시 1 Unit 추가 매수.
* **익절 및 청산**:
  * **다이나믹 트레일링 스탑 (Dynamic Trailing Stop)**:
    * 1~3회차 (가벼운 상태): **+10.0%** 도달 시 고점 추적 가동
    * 4~6회차 (물량 누적): **+7.0%** 도달 시 고점 추적 가동
    * 7~20회차 (대규모 물량): **+5.0%** 도달 시 신속 익절 리셋
    * 고점 대비 **-3.0%** 하락 시 전량 시장가 조기 익절 청산.
  * 5/20 MA 데드크로스 발생 시 포지션 정리.
* **최후 방어선**: 긴급 재난 손절 **-10.0%** (블랙스완 방어).

#### 🔴 하락 국면 (BEAR: 현재가 <= 200 MA)
* **국면 전환 시 부분 손절 (Risk Mitigation)**:
  * **이더리움 (ETH)**: 200선 하향 이탈 시 **50% 부분 손절** ➔ 남은 50%를 마틴게일로 인계하여 탈출.
  * **솔라나 (SOL)**: 200선 하향 이탈 시 **70% 부분 손절** ➔ 남은 30%만 마틴게일로 인계하여 폭락 위험 차단.
* **스쿼드 마틴게일(Squad Martingale) & 매직스플릿 이중 익절**:
  * **물타기 간격**: 평단가 대비 **-4.0%** 하락 시마다 순차 추가 매수.
  * **1 스쿼드 = `[1, 1, 2, 4]` 배수 투입 (총 8 Units = 80,000원)**:
    * **솔라나 (KRW-SOL)**: 1-1-2-4 스쿼드 4번 투입 (총 16차수 / 32 Units = 32만 원 캡 후 매수 중단 및 반등 대기).
    * **이더리움 (KRW-ETH)**: 1-1-2-4 무제한 순환 스쿼드 (1-1-2-4-1-1-2-4... 예수금 한도 내 영구 순환 탈출).
  * **매직스플릿 이중 익절(Dual Exit)**:
    1. **바스켓 전체 익절**: 전체 평단가 대비 목표 도달 시 일괄 청산 (SOL **+0.5%**, ETH **+0.8%**).
    2. **개별 차수 단독 익절**: 각 물타기 차수 진입가 대비 **+3.0%** 반등 시 해당 차수만 개별 익절하여 현금 회수.

## 🛡️ 3. 자산 보호 및 안전장치

1. **기존 보유 자산 완전 격리 보호 (`PROTECTED_BALANCES`)**:
   * 봇 구동 이전 사용자가 보유하던 자산은 봇의 손절 및 매도 대상에서 원천 배제됩니다.
   * `KRW-BTC`: 0.037415 BTC 전량 보호 (모으기만 수행)
   * `KRW-ETH`: 0.407562 ETH 전량 보호
   * `KRW-SOL`: 6.668875 SOL 전량 보호
2. **예수금 10만 원 미만 경고 알림 (`MIN_KRW_ALERT_THRESHOLD`)**:
   * 주문 가능 원화가 100,000원 이하로 떨어지면 텔레그램으로 경고 발송 (1시간 도배 방지 쿨다운 적용).

## 🖥️ 5. 실시간 모니터링 대시보드 (Streamlit)

로컬 및 Streamlit Cloud에서 실시간으로 포트폴리오와 퀀트 지표를 모니터링할 수 있습니다.

```bash
# 로컬 대시보드 실행
streamlit run dashboard.py --server.port 8501
```

* **접속 주소**: `http://localhost:8501`
* **주요 화면 구성**:
  1. **헤더 & 예수금 알림**: 실시간 실전 매매 모드, 예수금 부족 시 붉은색 경고 배너.
  2. **전체 계좌 포트폴리오**: 총 평가금액, 순손익률, 비중 파이 차트 및 자산표 (`KRW ➔ BTC ➔ ETH ➔ SOL`).
  3. **전략별 실시간 현황 카드**:
     * **전략 1. 비트코인(BTC)**: 현재가, 200일선, 계좌 평단가, 금일 종가 판정, 무손절 축적 현황.
     * **전략 2. 이더리움(ETH)**: 200 MA 국면, 5/20 MA 신호, 스쿼드 차수, 트레일링 스탑, 실시간 타임라인.
     * **전략 3. 솔라나(SOL)**: 200 MA 국면, 16차수 캡 상태, 바스켓 익절 목표가, 개별 체결 로그.
  4. **클라우드 스냅샷 동기화**: `utils/sync_manager.py`를 통해 GitHub Secrets 암호화 키 기반 클라우드 자동 동기화.

## 🚀 7. 설치 및 시작하기

### 1) 환경 준비 및 패키지 설치
```bash
# 저장소 복제
git clone https://github.com/oxyzenguy/autobot-trader.git
cd autobot-trader

# 가상환경 생성 및 활성화
python3 -m venv venv
source venv/bin/activate

# 필수 라이브러리 설치
pip install pyupbit pandas numpy streamlit plotly requests python-dotenv cryptography
```

### 2) `.env` 환경 변수 설정
프로젝트 루트 경로에 `.env` 파일을 생성하고 아래와 같이 설정합니다:
```ini
UPBIT_ACCESS_KEY="당신의_업비트_ACCESS_KEY"
UPBIT_SECRET_KEY="당신의_업비트_SECRET_KEY"

TELEGRAM_TOKEN="당신의_텔레그램_봇_TOKEN"
TELEGRAM_CHAT_ID="당신의_텔레그램_CHAT_ID"

# 종목별 총 투자금 배정 (순서: 1. 비트코인, 2. 이더리움, 3. 솔라나)
INVEST_KRW_BTC=1000000   # 비트코인 100만 원 (1Unit = 10,000원)
INVEST_KRW_ETH=1000000   # 이더리움 100만 원 (1Unit = 10,000원)
INVEST_KRW_SOL=1000000   # 솔라나 100만 원 (1Unit = 10,000원)

IS_PAPER_TRADING=false
```

### 3) 실전 매매 봇 실행
```bash
# 백그라운드 무중단 실행 (로그는 bot.log에 기록)
./venv/bin/python3 -u main.py > bot.log 2>&1 &

# 로그 실시간 확인
tail -f bot.log
```
