# 전략 변경 이력

## 2026-09-27 — ETH 200시간선 휩쏘 방어

### 관찰된 문제

- `KRW-ETH`가 200시간 이동평균선 부근에서 흔들린 2026-09-27에, 진행 중인 02:00 1시간봉의 일시 가격 `3,641,000원`이 200시간선 아래로 내려가며 상승장 포지션 청산이 발동했다.
- 해당 봉의 확정 종가는 `3,644,000원`으로 200시간선 위였으며, 확정봉 기준 05:00/06:00의 이격도도 각각 `-0.078%`, `+0.149%`에 불과했다. 추세 전환보다 경계선 잡음에 가까운 움직임이었다.
- `REGIME_SWITCH_PARTIAL_CUT_50PCT` 체결이 네 번 발생해, 설정 의도인 50%보다 훨씬 큰 규모가 청산됐다. 동일 마켓 봇의 중복 실행 가능성을 차단해야 한다.

### 변경 내용

1. 실시간 1시간봉의 미확정 가격을 200시간선 국면 판정에서 제외한다.
2. 200시간선 대비 ±0.1% 완충 구간을 둔다.
3. 완충 구간 밖에서 2개 연속으로 마감한 1시간봉이 있을 때만 BULL 또는 BEAR 전환을 확정한다.
4. 확인 대기 중에는 현재 국면과 보유 포지션 관리를 유지하되 신규 진입 신호는 발생시키지 않는다.
5. 마켓별 프로세스 잠금을 도입해 이미 같은 마켓을 제어하는 봇이 있으면 두 번째 프로세스를 시작하지 않는다.

### 검증 기준

- 과거 문제 구간의 `3,641,000원` 장중 가격은 기존 로직에서 BEAR였으나, 변경 후에는 직전 확정봉을 사용해 BULL 상태를 유지해야 한다.
- ±0.1% 안쪽인 확정봉 이탈/재진입은 어느 쪽도 새 국면으로 확정하지 않아야 한다.
- 같은 `KRW-ETH` 마켓으로 두 번째 봇을 시작하면 주문을 만들지 않고 즉시 종료해야 한다.

### 검증 결과

- 2026-09-27 ETH 1시간봉 재생에서 기존 로직은 02:15 장중 가격 기준 `BEAR`(`-0.026%`)를 반환했다. 변경 로직은 직전 확정 00:00/01:00 봉을 사용해 `BULL`을 유지했다.
- 확정봉 경계 구간은 05:00(`+0.004%`, `-0.078%`)와 06:00(`-0.078%`, `+0.149%`) 모두 `HOLD`로 판정돼 국면 청산이나 재진입을 만들지 않았다.
- 실제 `acquire_market_process_lock` 함수를 같은 마켓 식별자로 두 번 호출했을 때 첫 호출은 `ACQUIRED`, 두 번째 호출은 `BLOCKED`였다.
- `config.py`, `strategy/hybrid_regime.py`, `main.py`의 Python 구문 컴파일을 통과했다.

### 후속 점검

- 실계좌 적용 전 최근 1~2년 ETH 1시간봉을 사용해 완충폭과 확인봉 수의 수익률·MDD 영향을 백테스트한다.
- 운영 중인 기존 봇 프로세스는 변경된 파일을 읽지 않으므로, 배포 시 기존 프로세스를 한 번만 정상 종료한 뒤 새 프로세스로 재시작한다.
